# LUCID

**Sensory Neutral Augmentative & Alternative Communication.**
*Perfect clarity in a loud world.*

LUCID is an offline-first AAC web app. A person taps a large, predictable button and their own natural voice — generated by ElevenLabs — speaks instantly, with or without an internet connection.

## What it is (and is not)

- **Is:** a low-cognitive-load, sensory-neutral communication tool. No points, no avatars, no gamification, no decorative animation.
- **Is not:** a medical device, diagnostic, or emergency-response system. It does not replace adult supervision or emergency services.

## How it works

1. A caregiver adds phrases and picks a natural ElevenLabs voice that fits the person's age, accent, and personality.
2. While online, LUCID generates and caches every saved phrase as an MP3.
3. The cache lives in `audio/` and is served immutably; the app shell and cache are also copied by the service worker into the browser's offline store.
4. When the network drops (store, tunnel, garage, theater), tapping a button still plays the cached clip instantly. Speech never waits on the network.

## Run locally

```bash
cp .env.example .env   # then set ELEVENLABS_API_KEY
npm install
npm start              # http://localhost:3000
```

## Deploy to Railway

1. Push this repo to GitHub.
2. In Railway, **New Project → Deploy from GitHub repo**.
3. Add `ELEVENLABS_API_KEY` (and optionally `ELEVENLABS_VOICE_ID`) as service variables.
4. Railway auto-detects the Node app via `package.json` + `railway.json` and runs `npm install` + `node server/index.js`.

## API

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/health` | liveness + whether an ElevenLabs key is set |
| GET | `/api/phrases` | phrases + cache status |
| POST | `/api/phrases` | add a phrase |
| POST | `/api/phrase/:id/generate` | synthesize one phrase to cache |
| POST | `/api/prepare` | synthesize all uncached phrases (offline prep) |
| DELETE | `/api/phrase/:id` | remove a non-core phrase |
| GET | `/api/voices` | list ElevenLabs voices |
| GET/POST | `/api/profile` | voice/context/alert settings |

## Design rules (non-negotiable)

- Core urgent buttons are fixed, always visible, and never reordered by context.
- Context vocabulary is additive only — it can add buttons, never move or remove core ones.
- `app/js/speak.js` is the single critical path (tap → cached audio → play). No network call belongs there.
- Audio writes are atomic: temp file → validate → rename. A failed download can never replace a working clip.
